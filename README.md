# Backend Engineering Lab

A hands-on learning repository documenting backend engineering concepts through practical implementations, experiments, and technical notes.

## Objectives

- Understand backend architecture and application design.
- Explore stateful and stateless systems.
- Implement authentication and authorization mechanisms.
- Develop RESTful APIs.
- Understand database integration and transaction management.
- Explore application security and distributed systems.

## Learning Modules

| Module | Topics | Implementations |
|---|---|---|
| Authentication | Sessions, JWT, OAuth 2.0, Spring Security | [Stateful vs Stateless & JWT](authentication/stateful-stateless-jwt/), [Spring Security Authentication](authentication/spring-security-authentication/) |
| API Development | REST APIs, validation, exception handling | Coming soon |

## Approach

Each module follows a practical learning approach:

1. Understand the underlying concepts.
2. Explore the architecture and design decisions.
3. Implement working examples.
4. Test and verify the implementation.
5. Document findings, challenges, and lessons learned.

## Technology Stack

The repository is technology-oriented rather than framework-specific. Implementations may use Java, Spring Boot, and other backend technologies as learning progresses.
